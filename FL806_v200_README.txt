FL8.0.6 插件累积更新 v2.0.0：野蛮人大修启动修复（2026-10-30）

安装
完全退出游戏，先备份同名目录，再将本包内全部文件夹复制到含 main.lua 的游戏根目录，
合并并覆盖。随后重新启动游戏。本包包含上一版 v1.9.9 的完整适配内容。
适用于你已更新至 FL8.0.6 的插件移植整合包，继续使用其游戏引擎与本体资源。

本次修复
1. 修复 lib/klove/image_db.lua 的 table index is nil：图片读取失败时不再使用空索引写入。
2. 图集的图片加载成功后才发布其帧与缓存标记；失败时保留已有有效图集和引用计数。
3. 图片缺失、解码失败或格式不受支持时记录具体文件信息，可在修正资源后重试。
4. 支持 PNG、DDS、ASTC、JPG/JPEG、PKM 的现有文件与显卡能力匹配。
   缺少 PNG 但已提供可用 DDS 时可正常加载；支持 DXT5 而未报告 DXT3 时不再误拒绝。
5. 同时查找野蛮人插件目录、原生桌面图片目录与 fl_addons 目录。
   优先使用同一目录中完整配对的图集定义与图片，避免旧定义误配新版图片。
6. 野蛮人重新加载图集不再先删除原有图集；图片不可用时也不会把已知缺图排入加载队列。
7. 延迟图片读取失败后保留文件记录，后续可重试。

资源说明
目前收到的源码中只有 barbarianfl.lua 图集定义，没有野蛮人的原始图片。
若你本地已有原图，本补丁会在上述目录及可用格式中查找。
若本地也完全没有对应图片，该自定义图集会记录缺图信息并暂不加载；
其自定义网投、图标等画面仍需补回原始图片，加载保护不能恢复丢失的图像内容。
如仍提示缺图，只需提供对应 PNG/DDS/ASTC 图片及 barbarianfl.lua，无需重复上传整包。
